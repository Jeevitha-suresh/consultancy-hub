A full-stack job portal and consultancy management system that connects candidates, recruiters, and admin with secure role-based access.

---
## 🌐 Live Demo

🔗 [Consultancy Hub](https://consultancy-hub.vercel.app)

---
## ✨ Features

* 🔐 Role-based access (Admin, Recruiter, Candidate)
* 👩‍💼 Admin dashboard to manage recruiters
* 🧑‍💼 Recruiters can post and manage jobs
* 🧑‍🎓 Candidates can search and apply for jobs
* 📊 Application status tracking
* 📩 Interview notifications
* ⚡ Responsive and modern UI

---

## 🛠 Tech Stack

* **Frontend:** React (Vite), Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT, bcrypt

## ▶️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 📂 Project Structure

* `/backend` → API, routes, controllers, models
* `/frontend` → UI components and pages

---

## 🔐 Role Access Rules

* **Admin:** Pre-created, manages recruiters
* **Recruiter:** Added by admin only (no signup)
* **Candidate:** Can register and apply

---

## 🎯 Project Goal

To build a real-world consultancy platform with secure authentication, structured dashboards, and efficient job application flow.
